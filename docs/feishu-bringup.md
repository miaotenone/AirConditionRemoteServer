# 飞书联调

这是可复用的联调入口，不宣称任何个人生产实例当前在线。先完成
[飞书应用设置](feishu-setup.md)，本地按 [README](../README.md) 运行，
Linux 常驻服务按 [部署指南](deployment.md) 安装。

## 验证清单

在隔离测试设备与测试应用上，由操作者执行：

1. 唯一 owner 私聊 `设置卡片`：收到新遥控卡片，旧卡撤回或退化成提示；非 owner 不控制。
2. 点电源、模式、温度、风速：回调及时返回，状态最终与设备影子状态一致。
3. 连续点温度：去抖合并但相对步数不丢失；不把 publish 成功当物理执行确认。
4. 发 `状态` 不产生控制命令；`帮助` 给出语法；预设、天气、夜间、历史入口正常。
5. 网络异常不阻塞心跳线程；实际断网/失联验证须另选维护窗口。

无网络回归：`uv run --frozen --extra dev python -m pytest -q`。
`scripts/feishu_menu.py` 会读取配置并访问远端，`--apply` 更会修改菜单，
不得当离线验证命令运行。
